The pipeline

Five agents, one journey

📝

Intake Agent

Merges your form answers with facts mined from a free-text note — "my father passed away last year" becomes structured profile data.

🔍

Discovery Agent

Searches the indexed scheme database — central and state — for everything that could apply to you.

⚖️

Eligibility Agent

Runs a deterministic rule engine, never an AI guess. Every verdict comes with its reasons; every unknown becomes a question, not a rejection.

📄

Document Agent

Builds one consolidated checklist across all your matched schemes and marks what you already have.

🔗

Verification Agent

Every link comes from a curated official-source database with a last-verified date — never generated, never guessed.
